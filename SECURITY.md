# Security policy

## Supported version

Security corrections to this documentation are applied to the latest version
on the default branch. Product security fixes are tracked in the
[P-BitM repository](https://github.com/P-BitM-Framework/P-BitM).

## Reporting a vulnerability

Do not open a public issue, discussion, or pull request for a suspected
vulnerability. Email
[GiacoLenzo2109@proton.me](mailto:GiacoLenzo2109@proton.me) and include:

- the affected repository, component, page, and version or commit;
- the conditions required to reproduce the issue;
- a minimal proof of concept using non-sensitive test data;
- the expected security impact;
- any suggested mitigation.

Do not include real credentials, captured data, production targets, tracking
identifiers, browser profiles, or personal information. Submission does not
guarantee acceptance, a response, or a patch.

## Documentation-specific scope

Report malicious or unsafe instructions, leaked secrets, unsafe executable
examples, compromised published content, and links that create a material
security risk. Typographical errors, stale wording without security impact,
and general usability problems can be reported through a normal documentation
issue.

P-BitM is intended for authorized security testing in isolated environments.
Operators remain responsible for permission, data protection, and compliance
with applicable laws and policies.
